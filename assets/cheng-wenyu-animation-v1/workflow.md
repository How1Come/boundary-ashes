# 程闻屿锁定主体循环动画（v1 规划）

- 母版：`keyframe-01.png`
- 当前状态：静止底图已接入标题页与 HUD
- 计划规格：16 张关键帧、4 秒无声无缝循环；最终视频保持与标题页母版相同构图

## 锁定规则

每一帧必须完整复用同一张母版。脸部、五官、头部位置、颈部、躯干、四肢、双手、髋部、双腿、靴子、服装主体和镜头保持逐像素对齐，不允许重绘、缩放、旋转、平移或形变。

动态仅允许存在于独立透明覆盖层：

1. 两侧外轮廓长发的末端与少量分离发丝；所有发根固定。
2. 外套下摆、袖口自由边缘、薄荷色垂带和腰侧挂带；连接处固定。
3. 后续加入的机器人叶片、环轨、核心呼吸光和微粒；机器人机体中心保持固定轨迹。

帧序列必须以第 1 帧和第 16 帧之间的连续相位收束实现无缝循环。任何动态像素都不得进入脸、胸腹、双手、髋部和双腿核心锁定区。
