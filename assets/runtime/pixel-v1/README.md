# Pixel gameplay asset pack v1

Four original atlases generated with the built-in image generation workflow and consumed by the canvas renderer.

- `floor-atlas.png`: four fixed floor materials for the three dungeon layers and tutorial room.
- `entity-atlas.png`: two heroes, four robots, four normal enemies, anchor, two boss phases and dummy.
- `prop-atlas.png`: four solid props, four two-state mechanisms and four decorative fixtures.
- `vfx-atlas.png`: sixteen combat-readable impact, support, movement and boss effects.

Runtime rules: nearest-neighbour sampling, integer placement, 4×4 or 2×2 cell cropping, gameplay collision independent from sprite bounds. The attached reference screenshots were used only for high-level readability cues; all subjects, palettes and layouts are original.

Final prompt set: `stylized-concept`, strict top-down 2D pixel art, hard pixel clusters, limited dark-fantasy palette, no text, no logos, no watermarks, no copied characters or map layouts.
